# MY2026 CBP measure specification

## Multiple blood pressure readings on the same date

When multiple blood pressure readings occur on the same date, use the lowest systolic value and the lowest diastolic value from that date to determine the representative result. The selected systolic and diastolic values do not need to come from the same reading. Controlled blood pressure requires systolic below 140 and diastolic below 90.

## Acute inpatient and emergency department settings

A blood pressure reading taken during an acute inpatient stay or emergency department visit is not accepted as numerator evidence. Confirm the care setting before applying the reading-selection rule.

## Evidence needed when a qualifying value does not appear in the numerator

Confirm that the reading date is eligible, the care setting is permitted, and the submitted claim or supplemental record carries the expected place-of-service and blood-pressure reporting codes. If the care setting is unknown, use the POS code or claim code to determine whether the reading is acceptable. A value can be within range and still fail numerator inclusion when the source, setting, date, code, modifier, or downstream load does not satisfy implementation requirements.

## Monthly compliance regression investigation

When a member changes from compliant to noncompliant between monthly runs, first confirm the latest blood-pressure value and whether its care setting is accepted. If the clinical evidence is compliant, compare the current run with the prior compliant run. Verify that the same qualifying source data was received, determine whether a claim was adjusted or reversed, check for a later reading, validate the source and place-of-service, confirm that the expected reporting code and result value are present, and confirm that the record reached numerator staging. Independent laboratory evidence, including POS 81, requires source-acceptability review against the applicable measure specification.
