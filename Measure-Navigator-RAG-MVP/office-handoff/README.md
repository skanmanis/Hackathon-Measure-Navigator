# Office Handoff — Start Here

This folder contains a transfer-safe continuation package for Measure Navigator. It intentionally contains only plain-text and Markdown documentation.

## Files

1. `01_START_HERE_PROMPT.txt` — paste this into the office coding assistant after opening the project in VS Code.
2. `02_SOLUTION_ARCHITECTURE.md` — complete UI, ingestion, retrieval, controller, LLM, and CBP workflow design with Mermaid diagrams.
3. `03_OFFICE_INPUT_CHECKLIST.md` — source-path and environment checklist.
4. `04_ACCEPTANCE_TESTS.md` — end-to-end validation scenarios.

## Recommended transfer

Prefer the approved Git repository or copy these individual `.txt` and `.md` files using an approved corporate channel. These handoff files contain no executable code, macros, API keys, credentials, database files, vector indexes, or proprietary office documents.

Do not add NCQA specifications, office VSD/MLD files, stored procedures, credentials, `.env` files, or generated ChromaDB index contents to a public repository.
