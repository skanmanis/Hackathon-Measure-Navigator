The design must be reviewed and confirmed before implementation begins.

- `SOLUTION_ARCHITECTURE.md`: proposed governed hybrid RAG, deterministic evaluation, LLM reasoning, and memory architecture
- `DECISION_TREE_CRITICAL_REVIEW.md`: critical assessment and retirement recommendation for the existing decision-tree approach
- `SQL_TO_ENGLISH_RAG_DESIGN.md`: proposed SQL-to-English generation, review, chunking and RAG design
- `SOLUTION_COMPARISON.md`: comparison of the current prototype and proposed solution
- `DESIGN_DECISIONS_TO_CONFIRM.md`: decisions requiring approval before implementation
